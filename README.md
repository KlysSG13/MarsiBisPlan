# MarsiBisPlan — планировщик коммерческих пространств

**Живое демо:** [klyssg13.github.io/MarsiBisPlan](https://klyssg13.github.io/MarsiBisPlan/) *(включите GitHub Pages: Settings → Pages → ветка `main`, папка `/` — см. ниже)*

Научно-обоснованный планировщик **выставочных стендов, торговых и бизнес-помещений и коммерческих композиций**: раскладывает объект на зоны, вычисляет их приоритеты, подбирает оптимальную последовательность приёмов продаж, проверяет совместимость зон и подтверждает план на виртуальном потоке из 10 000 посетителей — до того, как потрачены деньги на реальном объекте.

## Что внутри

- **`index.html`** — весь сервис одним автономным файлом (~190 КБ): без сборки, зависимостей и сервера. Откройте в любом браузере — всё работает локально.
- **`financial_model.xlsx`** — живая финансовая модель монетизации: freemium-воронка, прогноз на 24 месяца, три сценария, чувствительность, безубыточность, юнит-экономика.
- **`PROJECT.md`** — полное описание проекта: цели, научный фундамент, функции, статус.

## Как это работает (4 слоя)

1. **Декомпозиция (метод МАРСИ)** — объект режется на атомарные зоны; каждая оценивается 8 вопросами по шкале 0–1, считается вес зоны и выделяется корневая зона ★ — точка максимального влияния. Есть пошаговая анкета зоны с кнопкой «Не знаю» (честно ставит среднее и снижает достоверность оценки).
2. **Воронка продаж (марковский процесс принятия решений)** — состояние посетителя на шкале «холод → горячо» (−1…+1), этапы TOFU → MOFU → BOFU, приёмы продаж со стохастическими эффектами и стоимостью; оптимальная стратегия π* ищется динамическим программированием.
3. **Композиция («клей» Φjk)** — совместимость пар зон: синергия / конфликт / запрет; компоновщик собирает лучший набор зон в рамках бюджета.
4. **Имитационная проверка** — 10 000 виртуальных посетителей; стратегия π* сравнивается со случайной, типовой и жадной; доверительные интервалы (бутстреп) и анализ чувствительности.

Ядро полностью детерминировано — без нейросетей; калибровка силы приёмов опирается на мета-анализы психологии влияния (Чалдини). В браузере доступна самопроверка движка на контрольном численном примере.

## Функции

- 4 типа объектов (стенд / ритейл / услуги / композиция), 7 профилей аудитории, пресеты цели по ключевым словам («максимум сделок», «сбор лидов», «узнаваемость», «средний чек»);
- анкета зоны со шкалами-подсказками и ориентирами «где брать числа»;
- траектория покупателя с углами отклонения от цели, автомат этапов, оптимальная последовательность приёмов;
- симуляция в фоновом Web Worker, гипотезы H1–H3, экспорт конфигураций JSON, печать итогового плана в PDF;
- встроенный словарь ~70 терминов: подчёркнутые слова по всему интерфейсу открывают карточки-пояснения;
- freemium-механика: тарифы Free / Pro / Business, коды активации с офлайн-проверкой по SHA-256, шаблоны юридических документов (оферта, 152-ФЗ, чеки 422-ФЗ).

## Быстрый старт

```bash
git clone https://github.com/KlysSG13/MarsiBisPlan.git
open MarsiBisPlan/index.html   # macOS; или просто откройте index.html в браузере
```

Для живого демо включите GitHub Pages: **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save**.

## Технологии

HTML + CSS + чистый JavaScript, ноль зависимостей; localStorage для данных; Web Crypto (SHA-256) для активации; Web Worker для симуляций; печать через CSS `@media print`.
